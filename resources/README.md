Downloaded and extracted resources for:

Xie, G. (2020). "A novel Monte Carlo simulation procedure for modelling COVID-19 spread over time."

Files in this directory:

- `s41598-020-70091-1.pdf`: article PDF downloaded from Nature.
- `41598_2020_70091_MOESM1_ESM.docx`: supplementary Word document containing the R code.
- `41598_2020_70091_MOESM1_ESM.txt`: plain-text extraction of the supplementary DOCX for inspection.

Dataset note:

The paper states that the real datasets came from Our World in Data and were accessed on 2020-06-07, but it does not identify a frozen CSV filename, URL, or repository commit for the exact snapshot used. The CSV in this folder is therefore reconstructed from the supplementary code itself, which is the most certain recoverable version of the case series actually used in the analysis.

Upstream OWID data references:

- https://ourworldindata.org/coronavirus
- https://covid.ourworldindata.org/data/owid-covid-data.csv
- https://github.com/owid/covid-19-data
